# Independent evaluation protocol - v0.6.0

The lecturer's missing worksheets cannot be repaired by inventing evaluations. Use [Evaluator 1](evaluator-1.md), [Evaluator 2](evaluator-2.md) and [Evaluator 3](evaluator-3.md) separately; add fourth/fifth evaluators if feasible. These files are blank templates, not evidence of completed evaluation.

Give every evaluator the same tested build, task list and severity scale. They inspect independently before discussing findings. Each records the screen/task, heuristic, severity, what happened, expected behaviour, screenshot/evidence and proposed response. Save original worksheets before aggregation. Remove participant contact details and obtain consent before recordings.

Tasks: sign in/create a customer account; choose/customise a service; create a wash-bay and mobile booking; allow/deny GPS and manually adjust a pin; submit reference/image evidence; view status; request cancellation/reschedule. An authorised administrator separately checks shared availability, payment verification, completion and receipts. Use fictional financial/customer data. Demo mode cannot test shared accounts or real proof-image storage.

Heuristics: system-status visibility; match to the user's language; user control; consistency; error prevention; recognition rather than recall; efficiency; focused presentation; useful errors/recovery; help. Severity: 0 observation, 1 cosmetic, 2 minor difficulty, 3 major difficulty, 4 task blocked. Record the evidence supporting the rating.

After independent inspection, deduplicate in [the iteration log](../TEAM-FEEDBACK.md) without deleting original observations. Assign a stable finding ID, requirement, change/defer decision, actual commit and retest result. A reasoned deferred issue stays visible.

For usability, use [the task record](usability-record.md) with at least three representative intended users. Do not coach during the measured task; record assistance separately. Report the number succeeding unaided and the denominator, not just a percentage. NFR-01 requires at least 80%; three participants therefore require three unaided successes. Do not claim it passed before collecting the observations.
