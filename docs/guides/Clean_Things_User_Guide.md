# Clean Things User Guide

**Guide version 1.2 • 3 October 2026 • Customers and peer testers**  
**Submission edition:** 3 October 2026  
**App:** v0.6.10-live

Install Clean Things, create an account and follow a booking from service selection to payment and receipt.

## 1. Install the application

You need Android 7.0 or later, internet access, a reachable email address and free storage. The APK is for Android phones and does not install on an iPhone.

1. Get `CleanThings-Live-v0.6.10.apk` from the project owner, or a later approved replacement. Download the actual APK attachment.
2. Open Downloads or My Files and tap the APK. For an existing installation, try installing the update over it first.
3. If prompted, open Settings and enable **Allow from this source** for the browser or file manager opening the APK.
4. Return to the installer, tap **Install**, then **Open**. Turn off **Allow from this source** afterwards.
5. Open Android Settings → Apps → Clean Things → App info. Check that the app version is **0.6.10-live**. Open Clean Things, rather than Clean Things QA.

If installation reports an invalid package, signature conflict or security block, send the exact message to the project owner. Obtain a verified replacement; do not turn off Play Protect to bypass a warning.

## 2. Open the app and sign in

Use the bottom navigation to move between the main customer screens.

1. **Home** gives the overview. **Services** shows packages. **Bookings** holds your requests. **Account** contains sign-in and profile settings.
2. Tap **Account**, then **Sign in**. Enter your registered email and password, scroll down if needed and tap **Sign in**.
3. If you are new, choose **Create account** instead. You can browse packages before signing in, but a booking requires an account.

Check the installed version using Android App info. A telephone/demo-role login screen indicates an older or different build. Some explanatory labels in v0.6.10 still contain “demo”; that word alone does not identify the connection mode.

## 3. Create your account

The registration form continues below the first screen. Use your own details.

1. In Account, tap **Create account**. Enter Full name, Telephone and Email. A Guyana number may include **+592**.
2. Scroll down. Set a password with at least eight characters, a letter and a number. Repeat it in Confirm password, then tap **Create account** once.
3. Follow the result shown. If confirmation is requested, open the newest confirmation email, then return to Sign in.

If already registered, use the existing account or reset its password.

Email confirmation depends on the server settings. Check the email address carefully and wait for any resend timer. Never share your password or confirmation link with a tester.

## 4. Save a login for biometrics

Use this optional feature on your own compatible phone. It signs you into your account.

1. Enrol a fingerprint or supported face in Android settings. In Clean Things, enter your email and password and tick **Save login for biometric sign-in**.
2. Tap **Sign in** and complete the phone’s biometric prompt when asked to save the login.
3. After a successful save, you can sign out and return later. Tap **Sign in with biometrics** and complete the Android prompt. Internet access is still required.

Anyone with a fingerprint or supported face enrolled on this phone can use the saved login. Do not save it on a shared phone. Signing out keeps it saved. If biometrics are unavailable, use your password. After changing your password, sign in with the new one and save it again.

## 5. Recover access and remove saved login

Use password recovery when you cannot sign in. Remove saved access before sharing a phone.

1. Enter your registered email in Sign in, then tap **Reset password**. The message does not confirm whether an account exists.
2. Check inbox and spam. Open the newest recovery email, follow its page to set a new password, then return to the app. Request a new link if the old one expired or was used.
3. To remove biometric access, choose **Forget saved login** in Account or on the sign-in screen. Also tap **Sign out** if you want to end the current session.

Wait for any sign-in or resend countdown. Repeated taps do not shorten it. The recovery page and Android biometric prompt are outside the app screens. Contact the project owner if recovery fails; never send passwords, recovery links or verification codes.

## 6. Choose a service and add-ons

Start with **Book a service** on Home, or choose a package from Services.

1. Select a service. Read its description, included work, duration and displayed price.
2. Scroll down to **Customise your service**. Tick only the optional add-ons you want.
3. Check Estimated total in GYD, then tap **Continue to schedule**.

Example: GYD 3,000 plus GYD 800 gives GYD 3,800.

These example prices are not a quotation. Use the current catalogue and total shown in your app. The service selection is highlighted; untick an add-on if you no longer want it.

## 7. Choose an appointment and vehicle

The progress bar shows **Service, Schedule, Details and Review**.

1. Choose **Wash bay** to bring the vehicle to the business, or **On-location** for a visit to your address.
2. Select Appointment date and an available time, then tap **Continue**. The customer picker starts with tomorrow. A crossed-out slot cannot be selected.
3. Check Customer name and Telephone number. Enter Vehicle make/model and Registration. Scroll down for the location and service notes.

Weekday start times extend to 7:00 pm; weekend start times extend to 9:00 pm in this build. Only available times can be booked. Date formatting varies by phone. Wash-bay bookings do not require an on-location address or water-source confirmation.

## 8. Set the on-location address

For a visit, give a written address and confirm that a suitable water source is available.

1. Enter the street, village or town and a landmark in Service location. Tick **Suitable water source available**. Add useful service notes.
2. Turn on the phone’s Location setting, then tap **Pin my current location** and allow app access. Use **Choose manually** if GPS is unavailable or the vehicle is elsewhere.
3. Drag the map or tap a point to adjust the centre pin. Check the service entrance, then tap **Use this pinned location**. Return to the form and tap **Review booking**.

A map pin does not replace the written address. You may enter latitude and longitude manually. The map needs internet to load its tiles. The pin in the formatted guide is an illustrative location, not a customer address.

## 9. Review and submit the booking

Review the complete request before sending it to the business.

1. Check service, add-ons, appointment, customer details, vehicle, address and estimated total. Use **Back** to correct anything.
2. Tick the accuracy confirmation and tap **Submit booking** once. Wait for **Booking request sent**.
3. Keep the booking reference. Use **My bookings** to follow the request, or **View MMG details** to continue to payment.

A sent request is still **Pending confirmation** until an administrator accepts it. If the chosen slot becomes unavailable, select another. After a timeout, check Bookings before submitting again to avoid duplicates. The current accuracy checkbox includes the word “demo”.

## 10. Submit MMG payment evidence

Open **Pay with MMG** for the relevant booking, or **View MMG details** after submission.

1. Check amount, account name, MMG number and payment note. Use the real details displayed in your app. Sample-only details in documentation must not be used to pay.
2. Make the transfer through MMG outside Clean Things. **Copy payment note** copies the booking reference.
3. Return and enter the transaction reference, choose a proof image, or provide both. Tap **Submit for admin review** and wait for success.

Proof images must be JPEG, PNG or WebP, up to the displayed 3 MB limit. Selecting a file alone does not upload it. Submitting evidence does not transfer money or automatically verify payment. Ask the business about cash; this screen has no cash-payment button.

## 11. Check status and request changes

Booking status and payment status are separate. Read both on the booking card.

1. Open Bookings. **Pending confirmation** refers to the appointment; **Pending review** refers to submitted payment evidence.
2. For an active booking, tap **Reschedule** or **Cancel**. The request waits for administrator review.
3. Contact the business to agree any replacement date. Check the final status after the administrator acts. Pull down from the top of the browsing screen to refresh.

Reschedule and Cancel submit requests; they do not immediately change the appointment. **Confirmed** means accepted; **Completed** means marked finished; **Cancelled** means cancelled. **Paid** means accepted payment; **Rejected** means evidence was rejected.

The planned 15% fee for cancellation requests less than 24 hours before an appointment is **not implemented** in this build.

## 12. View and share a receipt

A receipt becomes available after the required payment and completion records are in place.

1. Open Bookings and locate the relevant record. When available, tap **View receipt**.
2. Check receipt number, booking reference, service, amount, method and date in Digital receipt.
3. Tap **Email** or **WhatsApp** to open the sharing action. Check the recipient and send through that app. Close the receipt with × when finished.

Sharing is manual: Clean Things does not automatically email or WhatsApp the receipt. If your receipt is missing, refresh and reopen the booking. Contact the business with the booking reference if it still does not appear.

## 13. Update your customer profile

Keep your contact and vehicle details current so future bookings use the right information.

1. Open Account and choose **Edit profile & photo**.
2. Change your name, telephone, vehicle, registration or default location. Your login email is read-only here.
3. Optionally choose a JPEG, PNG or WebP profile photo up to 3 MB. Scroll to **Save profile**, tap it and wait for success. **Remove current photo** appears when a photo exists.

Profile changes do not automatically rewrite older booking records. Ask the business to correct an existing booking. Use the appearance option in Account to switch between light and dark mode. The formatted guide screenshots use light mode.

## 14. Updates and troubleshooting

### Install an approved update

1. Get the new approved Live APK from the project owner. Check its version before sharing it with peers.
2. Open the APK and install it over the existing app first. Keep your login details available in case you must sign in again.
3. Check Android Settings → Apps → Clean Things → App info afterwards. The phone’s Android or One UI version is not the app version.

Uninstalling or clearing app data removes local preferences and saved biometric login. It does not itself delete the hosted account or bookings. If Android reports a signing conflict, send the message to the project owner before uninstalling.

### Resolve common problems

| Problem | What to do |
| --- | --- |
| Old interface appears | Check App info and the APK filename. Open Clean Things rather than Clean Things QA. Obtain the approved Live build. |
| App not installed | Download the complete APK again. Check storage and Android version. Report any package or signature error. |
| Incorrect login or retry timer | Use the registered email and correct password. Wait for the countdown. Use Reset password if needed. |
| Biometrics unavailable | Use your password. Check device support and enrolled biometrics. Save the new login after a password change. |
| Location missing or incorrect | Turn on phone Location and allow Clean Things location permission, then retry. Use manual placement and a written address if needed. |
| No appointment times | Choose another date. Slots may be occupied or blocked. Same-day customer booking is not offered by this build. |
| Proof image fails | Check internet, file type and size. Choose a smaller supported image. Wait for submission success. |
| Record or receipt missing | Refresh after restoring connectivity. Check whether the request already exists before submitting again. |

### Contact support with useful details

Contact the project owner or the business contact supplied with the APK. Include the app version, phone model, Android version, time of the problem, booking reference and steps that caused it. Add a screenshot with personal or payment details covered. Do not include passwords, recovery links or verification codes.
