# Submission guides

Final Clean Things submission documentation for 3 October 2026 belongs in this folder:

- `Clean_Things_User_Guide.docx` — installation, customer use, booking, payment evidence, receipts, biometrics and troubleshooting.
- `Clean_Things_Deployment_Guide.docx` — release baseline, configuration, database/security, build/signing, acceptance, recovery and future-work status.
- `Clean_Things_Administrative_Guide.docx` — administrator access, bookings, availability, services, payment review, receipts, security and daily controls.

These guides describe the frozen `v0.6.10-live` APK. The repository source itself remains at the older v0.6.2 baseline and must not be represented as reproducible v0.6.10 source.
