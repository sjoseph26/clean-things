## Physical-phone acceptance still required

1. Install the signed v0.6.10 APK over the existing app.
2. Sign out if already signed in. Enter email/password and tick **Save login for biometric sign-in**. Approve the Android biometric prompt.
3. Sign out, tap the fingerprint sign-in button and approve biometrics. Confirm the correct account opens and an administrator can use management and the Customer/Admin switch.
4. Cancel the biometric prompt and confirm password sign-in still works. Check that reopening/backgrounding an active session never shows an app lock.
5. Use **Forget saved login**, then save again. Verify failure offline and after a password or device-biometric change, with password recovery available.
6. Retest a real receipt-image upload and administrator image access, plus the v0.6.9 acceptance cases.

Record phone model, Android version and exact BIO-* code on failure. Automated native-envelope and browser fixtures do not exercise a real biometric sensor or Android Keystore. No working passwords, tokens, enrolment secrets or biometric data belong in evidence.
